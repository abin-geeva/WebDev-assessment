# Yeshwanth student portfolio

This is a separately themed copy of the student portfolio app. It uses the same Express/Mongoose API and portfolio and feedback fields as the main project, with its own `yeshwanth_portfolios` and `yeshwanth_feedbacks` MongoDB collections.

Run `npm install` if needed, then `npm start`. This copy uses port 3001 and the local `student_portfolios` MongoDB database. Open http://localhost:3001.
